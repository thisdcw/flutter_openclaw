# OpenClaw App Icon Sources

These files are the source of truth for the approved OpenClaw app icon design.

## Files

- `app_icon_master.png` is 1024x1024 full-tile icon for iOS/macOS/web using a dark rounded-square tile.
- `app_icon_android_foreground.png` is 1024x1024 transparent foreground symbol-only asset for Android adaptive export and must stay within adaptive safe margins.
- `app_icon_android_monochrome.png` is 1024x1024 monochrome symbol-only asset for Android themed icons.

## Approved Visual Rules

- Rounded square tile on a dark base.
- Fused O/C monogram with a single claw-like opening.
- Deep ocean blue to blue-cyan gradient family with a cool cyan-green AI glow adapted to the existing blue UI.
- Cyan body with restrained aqua-green edge.
- Professional tone with subtle claw character.
- Avoid: text, mascots, mirrored pincers, purple, white tile background, cute/cartoon treatment.
